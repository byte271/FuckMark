Limits

Public limit list for FuckMark 0.4.1. Frozen detector numbers are not regenerated here. The static website runs the product mix in the browser; it still is not a general watermark remover.

L01 — Sanitizers

Live five-layer mix does not restore under Mn-strip, default-ignorable strip, UnicodeSanitizer orderings, Mn then Me then UnicodeSanitizer, Mn then Me then UnicodeSanitizer then frozen Cf-strip, or the required sanitizer bundle. Frozen Gate v2 confirmation remains the historical mark-only arm (188/192 after Mn/DI strip).

L02 — Input domain

Latin, Greek, Cyrillic, Han, Kana, Hangul syllables, and emoji clusters are processed. Curly apostrophes and other punctuation stay in the visible text and are reported as first_unsupported. Arabic and other joining scripts are left unchanged. Inputs with no eligible letter or emoji sites stay unchanged.

L03 — Length and the 4096-site cap

Only the first 4096 eligible letter or emoji grapheme clusters receive insertions (five per site). A longer document is unchanged after that point. Status fields sites, last_index, and capped report that limit.

L04 — Detector evidence is not a product guarantee

Primary confirmation used GPT-2 / SynthID with 64-token samples (192 pairs). DistilGPT2 still used the GPT-2 tokenizer. Zero detections in a finite set is not a universal zero-rate. Not claimed: generic AI-authorship classifiers, unknown proprietary detectors, every SynthID deployment, C2PA, or a general reduction in AI detection rates.

L05 — This website

The npm static build ports the product CLI engine (insert, detect, strip, hard-machine spans). HuggingFace / SynthID research tools stay in Python. Opening these pages does not send your paste anywhere; there is no application server.

L06 — Chromium pixels

Live five-layer mix is Chromium pre-pixel REJECTED because enclosing Me (U+20DD) changes glyphs. Historical mark-only mix remains pixel-equal where measured. Safari/WebKit/terminal pixels remain UNKNOWN.

Full matrix: repository docs/limits.md. Tool: Mark / Unmark.
