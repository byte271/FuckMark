FuckMark no-install demo

Fixed CLI samples only. Shows character differences, processing status, sanitizer reversal, and frozen GPT-2 / SynthID numbers. This page does not score your text against a detector and does not guarantee results on any platform.

Sanitizer reversal is first-class. FuckMark only inserts U+034F and U+FE00. Clearing combining marks or default-ignorable characters restores the original text. On the frozen Gate v2 set that means detections go from 0/192 after required sanitizers back to 188/192. Parameter tuning cannot fix that under the insertion-only design.

Local paste inspector (no detector, no insertion)

Checks whether text is ordinary English ASCII the CLI accepts. It does not run the mix transform, does not protect Markdown/paths, and does not query any detector. The CLI remains the source of truth.

Unsupported Unicode returns exit 0 from the CLI with reason unsupported-domain. That is I/O success, not a completed transformation.
